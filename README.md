# HelloEarth website

A simple, calm, responsive landing page for a future student-management platform for tutors.

## Files
- `index.html` — site content
- `style.css` — layout and styling
- `script.js` — mobile navigation and coming-soon chat widget

Open `index.html` locally or publish these three files to GitHub Pages.

The dashboard uses sample data only. The chat widget is a coming-soon preview, not a working chatbot. Atlas AI integration is planned, not live. The contact email is a placeholder until configured.

Responsive layout tested at CSS breakpoints for narrow phones (320–360px), phones, tablets, laptops and large desktops. Includes mobile menu, safe-area-aware chat positioning, and reduced-motion support.
